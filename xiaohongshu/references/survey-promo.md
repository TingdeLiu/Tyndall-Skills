# 推广自己的综述文章

适用：作者要推广自己写的综述或长篇导读（如「空间智能综述」「深度学习综述」「机器学习综述」）。目标读者是刚入门、或读过一些却缺少全局认识的人；帖子要让人觉得「点进来能拿到一张全局地图」。

这类帖子固定用「带你看懂X」读者导向版式，**不套 SKILL.md「封面选题」里的钩子规则**。技巧型、反常识型钩子（如「Loss 降不下去，先别加 Dropout」）只当某一页内页的标题：放在封面上，读者会以为这只是一条小技巧，看不出背后有一整篇综述，吸引来的人也更少。

## 素材

- 原文优先读作者本地的源文件（Markdown 等），没有再抓网页。
- 综述引言若有总览配图，用作第 2 页。
- 文中的「阅读指南 / 阅读建议」节决定末页的阅读路线；「总结 / 选型 / 排错」节通常能出一页可直接用的方法。
- 有配套精读、论文列表等延伸内容时，先核对篇数与分组名，再写进封面和正文。

## 标题与正文

- 发布标题：`带你看懂<主题>`。文章原名（「XX综述」）保留在正文和末页，供读者搜索。
- 正文结构（参考 600–950 字）：
  1. 🤔 列一串读者听过的名词，问「放在一起却说不清它们之间是什么关系？」
  2. 一句「我写了一篇《XX综述》，想帮刚入门、或者……缺少全局认识的朋友，先搭起一张技术地图。」
  3. 📍 这篇综述能帮你理清什么：`1、` 到 `4、`，每条「问题：一句回答」。
  4. 💡 一个最常用的判断或例子：综述里最实用的一条。
  5. 🛠 建议的读法：按读者阶段给 2–3 条路线。
  6. 📌 阅读边界：覆盖了什么、没覆盖什么，数字以原论文设置为准。
  7. 🔎 告诉读者去哪里看全文（如「浏览器打开 <站点>，搜索「XX综述」」），正文不放长 URL。
  8. 标签 5–6 个，以 `#论文综述` 或同类精准标签收尾。
- 完整链接写进 `pinned-comment.txt`，交付时提醒作者自己置顶，不代发。

## 图组（6 张为默认，内容多可到 7 张）

| 序 | 页面 | 类型 | 内容 |
|---|---|---|---|
| 1 | 封面 | `artwork` | `svgkit.survey_cover_frame`：「带你看懂 / 主题」+ 一句副标题 + 原创场景插图 + 「A ＋ B ＋ C」三块内容 + 关键词行 |
| 2 | 全景 | `figure` | 综述引言的总览图，标明出处 |
| 3–5 | 机制页 | `figure` | 自绘 992 宽 SVG：技术演进、分类地图、选型/排错流程、核心对照等，各页一个问题 |
| 末 | 阅读入口 | `artwork` | `svgkit.reading_guide`：「先看全景 / 再选方向」+ 三条路线（读者 · 章节号 · 阅读顺序）+ 全文入口 |

封面插图要体现主题的机制，而不是装饰。例如：
- 空间智能：照片 → 三维房间 + 点云 + 「杯子在桌上」关系标注。
- 深度学习：一张猫图 → 逐层网络（边缘 → 纹理 → 部件 → 类别）→ 输出，Loss 梯度回传。
- 机器学习：同一份二维数据上线性 / 树 / 神经网络三种决策边界，右侧三张说明卡。

插图里的数据点、曲线一律标「示意，非实测」。主题超过 4 个汉字时，复制 `survey_cover_frame` 调小主题字号，并用 240px 预览确认。

内页 kicker 按 `01 / 全景`、`02 / …` 连续编号，末页接着编号。内页标题优先用问题或判断（「99% 准确率，可能一个都没找到」「AdamW 之后，优化器往哪走？」），要点 1–2 条，最后一条注明「据综述第 N 节整理（自绘）」。

## 帖子目录与构建

每篇一个目录：`body.txt` `title.txt` `pinned-comment.txt` `sources.md` `config.json` `build.py` `assets/` `cards/`。build.py 写各页 SVG → 截成 2x PNG → 调 `make_cards.py`；整页图直接用 `artwork` 类型。

```python
import sys; sys.path.insert(0, "<skill目录>/scripts")
from svgkit import *
```

重做时把旧版放进 `_archive/` 再改。

## 交付检查

- count.py 实测正文字数；标题 ≤ 20 字。
- 逐张看原图和 `_previews/`：封面 240px 能认出主题，内页 360px 能读清关键标签。
- `sources.md` 记下：原文路径与版本日期、每页依据的章节、引用的原图、哪些是自绘示意。
