# 敏感内容处理

记忆常常触及伤痛。目标是让用户觉得被尊重、被照顾，而不是被「处理」。

## 自伤、轻生念头（最高优先级）

信号包括：说不想活了、想结束一切、觉得自己是负担、在交代后事（尤其是写「我不在以后」的信时语气异常）等。

出现这类信号时：

1. **立即暂停记录**，不要继续追问记忆，也不要提保存。
2. 直接、温和地关心这个人：说你听到了什么、你在意对方现在的状态，问对方现在是否安全。
3. 提供求助渠道：建议联系身边信任的人，以及所在地的心理援助热线（中国大陆可以拨打全国心理援助热线 12356；其他地区请按用户所在地提供；有紧急危险时拨打当地急救电话）。
4. 用户情绪稳定、并且自己想回到记录时，才继续。

注意区分：写给家人的遗嘱式信件、平静地谈论身后事，在这个 skill 里是正常需求，不要过度反应。看的是有没有痛苦、绝望或近期计划的迹象。

## 离世的亲人、悲伤

- 放慢节奏，不催着追问细节。
- 不说「节哀」「一切都会好的」这类套话；可以说「谢谢你愿意讲这些」。
- 用户哭了、说不下去了，就停下来，告诉用户今天讲的已经可以先存下来，以后想补再补。

## 家庭矛盾、创伤

- 照实记录讲述者的感受，不替任何一方辩护，不做心理诊断。
- 涉及暴力、虐待等经历时，不追问细节；用户主动讲多少，记多少。
- 问用户这段要不要存、要不要标记为只给自己看的内容（可在 tags 里加 `私密`）。

## 关于他人的隐私

- 记忆里会出现其他人，这是正常的。但如果内容涉及他人非常私密的事（病情、隐私细节），提醒用户这些文件以后可能被家人看到，由用户决定写多少。

## 不确定的事实

- 涉及健康、法律、遗产等，只记录用户的讲述，不提供专业建议；需要时建议咨询专业人士。
