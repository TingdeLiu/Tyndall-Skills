# 首次引导

第一次用本技能聊天，在自然的停顿介绍一次日常记忆和推荐文件夹。库主可选自动记忆、手动保存或只聊。

## 步骤

### 1. 一句话介绍 + 推荐文件夹

不要让用户自己去找路径。先运行 `python scripts/memory_vault.py suggest`（英文用户加 `--language en`），它会返回这台电脑上「文档」文件夹的真实位置下的推荐路径（Windows 上「文档」常被重定向到 OneDrive，不能直接假设是 `~/Documents`）。把这个路径推荐给用户，用户回「好」就能继续。

脚本不能运行时，Windows 推荐 `<用户主目录>\Documents\我的记忆`，macOS / Linux 推荐 `~/Documents/我的记忆`。

例如：「我们可以边聊边熟悉起来。我会把你提过的重要经历和偏好留在自己的记忆库里，也会记住哪种聊法合你的心意。要在这个文件夹开启聊天记忆吗？」同时给出推荐路径。用户已经明确要求开启时，只需确定文件夹。

### 2. 创建记忆库

用户同意后运行（脚本路径相对于本 skill 目录）：

```
python scripts/memory_vault.py init "<vault_path>"
```

它会创建目录结构、`README.md`、`profile.md`、`SOUL.md`、`INDEX.md`，并写好 `~/.memory-keeper/config.json`。英文库运行 `init "<vault_path>" --language en`。

同意自动记忆后，对选定库运行 `chat-memory on --vault <vault_path>`；用户选手动或暂停就用 `off`。此设置只属于该库。缺少 Python 时保留手动方式，格式参照 [schema.md](schema.md)。

### 3. 简短的隐私说明（两句话）

> 文件只存在这个文件夹里，我不会上传到别处。不过我们聊的内容会经过 AI 服务商处理，特别私密的事你可以不讲，或者以后自己在文件里补上。

### 4. 马上开始第一段

根据用户来的目的选开场问题：

- 用户来设定聊天朋友 → 按已确认的要求修改 `SOUL.md`，用设定好的口吻开始聊。
- 用户想让 AI 了解自己 → 先聊当下。用户主动说想被采访时才一次问一句。
- 用户只是想聊天 → 照常回应，按当前库的聊天记忆设置处理值得留下的片段。
- 用户明确想采访亲人 → 进入「采访家人」流程，先问想采访谁。
- 用户没说具体想做什么 → 问一个**轻、具体、人人都有答案**的问题，例如：
  - 「先从一件小事开始吧：你小时候放学回家，最常吃的一样东西是什么？」
  - 「最近有没有哪个瞬间，让你突然想起了以前？」

不要问「请介绍一下你自己」这类大问题。`profile.md` 的内容在之后的聊天里慢慢补。

### 5. 第一段记忆写得要格外好

用户已经说「帮我记一下」并提供内容时，直接出一份简短预览。想深入聊时，顺着原话追问一两个细节，再确认保存。用户带来的照片、录音或视频可连同第一段存下。

### 6. 收尾

> 第一段记忆已经存到 `memories/2026-11-14-放学路上的烤红薯.md` 了，你可以打开看看。
>
> 下次聊到这段日子，你可以问「我当时是怎么讲的？」。

## 注意

- 用户中途想跳过某步（比如不想听隐私说明），就跳过。
- 用户拒绝创建文件夹 → 照常聊和整理，把结果输出在对话里，并告诉用户随时可以再开启保存。
