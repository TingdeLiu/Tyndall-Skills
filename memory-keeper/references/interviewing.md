# 采访技巧与问题库

## 追问的原则

- **一次一个问题。** 不要一口气抛三个问题。
- **从具体到抽象。** 先问画面（在哪、谁在、看见什么、听见什么、什么味道），再问感受，最后才问「现在回头看怎么想」。
- **顺着对方的词追问。** 对方说「那时候苦」，就问「苦在哪？能说一件具体的事吗？」，不要换话题。
- **允许沉默和跑题。** 跑题常常引出更好的故事，记下来，之后再回到原话题。
- **不纠正、不评判。** 记忆和「事实」对不上很正常，照实记录讲述者的版本。
- **知道何时停。** 回答越来越短、语气变淡、或明确想结束时，就收尾整理。

## 好问题 vs 坏问题

| 不好 | 更好 |
|---|---|
| 你的童年是怎样的？ | 你小时候家里吃饭，谁坐在哪个位置？ |
| 你爱你的父亲吗？ | 你爸有没有一句话，你到现在还记得？ |
| 那段时间你感觉如何？ | 那天晚上回到家，你做的第一件事是什么？ |
| 能总结一下你的人生吗？ | 如果只能讲一件你最骄傲的事，会是哪件？ |

## 自己的记忆：开场问题

轻松入门：
- 小时候放学回家，最常吃的一样东西是什么？
- 你记得的第一个家，大门是什么颜色？
- 第一次自己赚到钱，买了什么？
- 有没有一首歌，一听就会想起某个时候？
- 最近有没有哪个瞬间，让你突然想起了以前？

深一点：
- 有没有一个人，改变了你走的路？
- 你做过最难的决定是什么？
- 有什么事，你一直想跟某个人说但没说出口？

## 采访家人：问题清单（按人生阶段）

适合采访父母、祖父母。问题要短、口语化，适合直接念给长辈听。

**童年**
1. 您小时候住在哪？家里房子是什么样的？
2. 小时候家里几口人？谁管事？
3. 小时候最喜欢玩什么？
4. 小时候过年是怎么过的？

**青年**
5. 您上学上到什么时候？那时候的学校什么样？
6. 第一份工作是做什么的？怎么找到的？
7. 年轻的时候，最想做的事是什么？

**成家**
8. 您和爸/妈是怎么认识的？第一次见面什么印象？
9. 结婚那天是怎么过的？
10. 我出生那天，您还记得什么？

**工作与生活**
11. 这辈子最辛苦的是哪几年？是怎么熬过来的？
12. 有没有哪件事，您到现在还觉得遗憾？
13. 您最骄傲的一件事是什么？

**想对孩子说的话**
14. 如果能对年轻时的自己说一句话，您会说什么？
15. 有什么话，想留给孙子孙女？

## 采访家人：给用户的小贴士

准备模式下把这些附在问题清单后面：

- **用手机录音。** 长辈讲话时尽量别打断，录下来回头再整理，比边听边打字自然得多。
- **从老照片聊起。** 拿出一张旧照片问「这是哪年拍的？」，往往比直接提问更容易打开话匣子。
- **别纠正。** 长辈记错年份没关系，先让故事讲完。
- **不必一次问完。** 每次聊二三十分钟，挑长辈有兴致的问题，剩下的下次再问。
- **回来后把录音转成文字发给我**（手机自带的录音转文字功能就可以），我帮你拆成一段段记忆存好。
