# 留下原声、图像和动作

以下命令接在 `python <skill 目录>/scripts/memory_vault.py` 后面。媒体和采访功能使用 Python 标准库。

## 把原件放回故事里

用户给出可读取的本地文件后，在原有的保存预览中列出准备复制的文件。支持常见手机照片（含 HEIC）、录音（含 M4A、WAV、AMR）和视频（含 MOV、MP4）。脚本分块复制原始字节，保留文件内的画质、声音和拍摄信息。已有同内容、同扩展名的副本会复用。用户原来的文件仍在原处。

```text
add 草稿.md --attach "外婆的讲述.m4a" --attach "老厨房.heic"
media <记忆id> "后来找到的合照.jpg"
media <记忆id>
```

用户只带来素材时，可以先用他们提供的描述建一条短记忆。已有故事就直接补附件。若聊天里只有文件名、缩略图或转写，说明当前拿到的材料，用户要保存原件时再请他们提供文件或可读取的路径。没有听到、看到或听清的部分保留待补。归档本身不会产生转写。

### 有顺序的做法

例如用户说「先折粽叶，再把米填进去」，正文按顺序写下这两步。若用户指出第二步在视频的 18 到 32 秒，把这个片段标到第二步。照片可以只标步骤。复用同一视频标记其他步骤时，保留各自的时间位置。

```text
media <记忆id> "包粽子.mov" --step 2 --at "00:18–00:32"
media <记忆id> "折好的粽叶.jpg" --step 1
```

为同一原件标记更多步骤时，可直接用 `media <记忆id> --reuse <清单返回的media/路径> --step 3 --at 00:46`。这样无需再连接手机或重新复制视频。

用户从故事的「原始素材」一节点开原件，用标出的时间找到动作。能否直接预览取决于设备上的播放器；HEIC 等格式保留原格式。HTML 书保留步骤顺序，给家人前可以单独挑选愿意分享的原件。完整采访可能同时讲到好几个人或私密的事。

## 家庭记忆卡

用户想把一段记忆给家人时，用 `search` 找到故事，打开正文，用 `media <记忆id>` 列出素材。让用户看见将交给收件人的正文和文件名。用户已经点名要哪件原件，就按其选择制作。只说「把这个故事做张卡」时默认只放文字。

```text
card <记忆id>
card <记忆id> --media <清单里的media/路径> --media <另一件原件的media/路径>
```

每个选中的文件都完整复制，包括拍摄信息和时间标记之外的内容。用户只想分享视频中几秒时，应使用其认可的裁剪副本；时间标记只定位播放位置。私密故事需明确同意分享这一篇，并加 `--include-private`。只交付 `exports/` 里的成品 ZIP，由用户决定发给谁。

家人收到后先解压整个 ZIP，在浏览器中打开 `index.html`。支持的格式直接显示或播放，也可以点「打开原件」用设备上的播放器。保留 `index.html` 和 `media/` 的相对位置即可离线观看。完整转写、人物档案和其他故事留在库里。

## 把一次采访分几次整理

1. 拿到 UTF-8 的转写或笔记，先确认可以在库里保留整份原文。用户在聊天里粘贴的转写可临时写入库内 UTF-8 文件。按话题找自然断点。默认以空行分段，也可以用 `--starts` 指明各段第一行（从 1 起，以原文件为准，空行也占行号）。保留转写已有的时间戳。
2. 开始后，从输出得到采访 id 和每段的原文行号。展示本次要整理的片段；取得保存确认后，给每篇草稿传入相应的采访 id 和段号。相同原文再次导入会找到已有进度；同一段再次归档会返回已有记忆 id。要修订该段，直接修改已有条目。
3. 下次打开新的对话，用 `interview list` 找到那次采访，用 `show` 看进度，再按段读取原话。尚待确认的片段保留在采访里，故事和导出的书只收已经归档的部分。

```text
interview start "爸爸的采访.txt" --title "爸爸讲第一次上班" --attach "现场录音.m4a"
interview list
interview show <采访id> --segment 2
add 第二段草稿.md --interview <采访id> --segment 2
```

采访中的每段记忆都链接到同一份原始转写，并标明对应行号。已有补充录音可用相同的转写再次运行 `interview start --attach`；`media <记忆id>` 也列出该场采访的原件。删除已归档的一段会把故事移入回收站，该段重新显示为待整理。媒体可能由其他故事或步骤共用，删除故事会保留原件；整库备份请同时包含 `media/` 和 `interviews/`。这两个目录和回收站都属于私人档案。
